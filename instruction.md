# Copilot Instructions for Sudoku Refactor

- **Framework:** Python backend (Flask) with Vanilla JS/CSS frontend.
- **Code Style:** Modular, reusable functions. Include clear docstrings for all Python functions.
- **Error Handling:** Ensure robust error handling for API routes and game logic.
- **UI/UX:** Use responsive design, CSS modules/framework, and support Dark/Light mode.
- **Accessibility:** Keep WCAG 2.1 AA standards in mind (good contrast, semantic HTML).
